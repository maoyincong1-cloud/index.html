# 日本生活ゴミ分別アシスト (Garbage Sorting Helper)

日本での生活において、地域ごとに異なる複雑なゴミ分別ルールを簡単に確認するための Web アプリケーションです。

## 💡 主な機能
- **簡単検索**: 日常生活で出るゴミの名前を入力するだけで、正しい分別方法（燃えるごみ、資源ごみ等）をすぐに確認できます。
- **直感的な操作**: シンプルな UI で、スマートフォンからも素早く利用可能です。

## 🛠 技術構成
- **フロントエンド**: HTML5, CSS3, JavaScript (DOM 操作)
- **ホスティング**: GitHub Pages を使用した静的サイトホスティング
