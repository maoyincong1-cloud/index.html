# 日本生活：近隣施設クイック検索ツール (Japan Life Quick Search)

日本での新生活をサポートするための、Web ベースの施設検索ポータルサイトです。
「今すぐ近くの施設を探したい」という場面で、複雑な操作を排除し、ボタン一つで Google マップの検索結果へアクセスできます。

## 💡 このツールの特徴
- **ワンタップ検索**: コンビニ、郵便局、病院、市役所など、生活に欠かせない施設を即座に検索。
- **軽量・高速**: 余計なデータベースや重いフレームワークを使わず、シンプルな HTML/CSS で構成。スマートフォンでの動作を最優先に設計しました。
- **高アクセシビリティ**: 日本語での直感的なインターフェースにより、言語の壁を最小限に抑えています。

## 🛠 技術構成
- **フロントエンド**: HTML5, CSS3 (Flexbox/Grid によるレイアウト)
- **統合 API**: Google Maps 検索クエリ・ディープリンク
- **ホスティング**: GitHub Pages (自動デプロイ設定済み)

## 📝 開発の背景
日本での生活において、地域ごとの施設場所を把握することは重要です。しかし、地図アプリを開いて検索ワードを入力するのは意外と手間がかかります。本ツールは、その「数秒の検索時間」を短縮し、迷いやすい公共施設へのアクセスを効率化することを目的に開発しました。
